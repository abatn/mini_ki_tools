# Mini KI Tools - Docker Import & Build Problem Investigation
## Ziel
Den Docker-Container zum Laufen bringen mit:
-TAO-Agent (nicht Dummy)
- Web-UI (HTML am / Endpoint)
- 12 LLM Providers
- 7 Reasoning Modi
## Problem Statement
### Problem 1: Relative Import Errors
- Fehler: `ImportError: attempted relative import with no known parent package`
- Ursache: `from .agent import Agent` in agent_server.py mit `python -m src.agent_server`
- Bereits versucht: PYTHONPATH=/app/src in Dockerfile
### Problem 2: Agent Return Value Mismatch  
- Fehler: `ValueError: too many values to unpack (expected 2)`
- Ursache: agent.py Zeile 8 gibt `result, history` zurück, Zeile 7 erwartet nur `result`
- Fix: In agent.py -> `return result` (nur String)
### Problem 3: Dockerfile Build Timeout
- BUILD: docker build -t mini-ki-tools . 
- Timeout: >300 Sekunden
- Ursache: Frontend npm install + build dauert zu lange
### Problem 4: Root Returns JSON Not HTML
- Erwartet: HTML (React App)
- Bekommen: `{"message":"Mini KI Tools API","version":"1.0.0"}`
- Ursache: frontend/build/index.html nicht gefunden
## Anforderungen
1. Alle relativen Imports durch absolute Imports ersetzen ODER PYTHONPATH korrekt setzen
2. Agent Return-Value fixen (nur String zurückgeben)
3. Docker Build unter 2 Minuten halten
4. Frontend serving funktioniert
